# 身体课表 · 迈开腿 管住嘴

一个帮你把运动**排成一张课表**、顺便记记吃的和体重的小工具。手机打开就能用，不用注册、不用登录，数据只存在你自己的设备上。

## 它能帮你做什么
- **排课表**：把想跟练的视频（B 站）和私教课排进一周里。横屏看整周，竖屏看每天。点一下「自动排这周」，它会按"同一部位隔天再练、别连着两天暴汗"这类简单规律帮你安排好；手动拖过的、私教课和已经练完的都不会被它乱动。
- **建卡片库**：粘贴一个 B 站链接，它自动帮你抓好标题、封面、时长；也能手动记一节私教课。
- **记饮食**：用「手掌法」随手记每餐——蛋白质一掌、蔬菜一拳、主食一捧、油脂一拇指，简单不折腾。
- **看进度**：体重趋势（看 7 天平均更准）、每周练了多少、一键导出一份周报。

## 关于你的数据
所有记录都**只保存在你这台设备的浏览器里**，没有账号、没有服务器，离线也能用。

想换手机/电脑，或者备份一份，去「数据」里：
- **导出备份 / 导入备份**：一个文件装下你全部的数据（卡片、课表、饮食、体重），换设备时导出再导入就行。
- **导出周报**：一份给人看的摘要，方便记进笔记或发给朋友，但不能用来还原数据。

## 一句话
它不打分、不催你，只是帮你把"想练的"变成"排好的"，再顺手记下身体和吃饭的变化。照顾好自己，就是完成。
